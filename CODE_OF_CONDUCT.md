# Code of conduct

Device Hub Pro follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussions about the work.
Harassment, insults and personal attacks are not tolerated in issues, pull requests,
discussions or any other project space.

To report unacceptable behaviour, use the repository's **Security** tab ▸ **Report a
vulnerability** (it reaches the maintainers privately) and say that it is a conduct report.
Reports are handled confidentially.
